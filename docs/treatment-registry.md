# Общий список мер

По запросу пользователя от 26 ноября 2026 добавлен общий список на `/treatments`. Это расширяет первоначальный объём документа 11, где отдельный глобальный реестр мер был исключён.

- `GET /api/v1/public/treatments?offset=0&limit=25` возвращает `items`, `hasMore`, `riskNames` и `processNames`
- Требуется действующая сессия и эффективное право `view_risk`; используется только база выбранного клиента
- `offset`: 0…2147483647; `limit`: 1…100, по умолчанию 25
- Порядок: `createdAt DESC, id DESC`; дополнительная строка определяет `hasMore`, но не включается в `items`
- Меры всех статусов, включая отменённые и завершённые, сохраняются в списке
- Названия рисков и процессов читаются пакетно для текущей страницы, включая неактивные процессы; нет обхода карточек по HTTP
- Чтение страницы и названий выполняется в одной транзакции `RepeatableRead`; данные не изменяются
- SPA хранит смещение в URL, отменяет устаревшее чтение при переходе на другую страницу и восстанавливает страницу после возврата из карточки
- Создание меры по-прежнему начинается в карточке риска с серверными проверками текущей оценки и режима обработки

Миграция не нужна. Swagger получает контракт из HTTP-контроллера и модели `TreatmentRegistry`. Сохранённый ранее OpenAPI-снимок не выдаётся за обновлённый: его нужно снять после сборки и запуска новой версии API.

## Проверка

Автоматические frontend-проверки покрывают запрос страницы, сохранение `hasMore` и названий, нулевые суммы и некорректные смещения. HTTP-проверки сервера добавлены в `Tests/Http/treatments.http`. Серверные сценарии требуют обновлённого запущенного API; сборка в этой задаче не запускалась.
